# Informasi Repository GitHub

**Nama repository**
`YG3FSL-LoRa-APRS-iGate`

**Description (English)**
Minimal RX-only LoRa APRS iGate using ESP32-C3 SuperMini, RA-02 (SX1278), and Wi-Fi to forward packets to APRS-IS.

**Description (Bahasa Indonesia)**
iGate LoRa APRS sederhana berbasis ESP32-C3 SuperMini dan RA-02 (SX1278), dengan forwarding paket ke APRS-IS melalui Wi-Fi.

**Topics**
`lora` `aprs` `igate` `esp32-c3` `sx1278` `ra-02` `aprs-is` `arduino` `ham-radio`

**Suggested visibility**
Public, jika memang ingin source code dan dokumentasi dapat dilihat orang lain.

**Catatan**
Periksa kembali koordinat `IGATE_LAT` dan `IGATE_LON` di firmware sebelum repository dipublikasikan. Koordinat itu juga digunakan untuk beacon posisi ke APRS-IS.
